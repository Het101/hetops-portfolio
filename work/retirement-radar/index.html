Retirement Radar

AWS now bills automatically for running old versions. EKS extended support alone is about $365 a month per cluster. This read-only CLI finds them first.

Role
Author and maintainer
Stack
Node.js CLI over the AWS CLI
Status
Open source on npm, 0.3.0
Source npm

The problem

Managed services retire versions on a schedule, and AWS now moves you onto paid extended support instead of breaking you. For EKS that is $0.60 an hour per cluster instead of $0.10: about $365 a month each, and nobody gets an email about it.

How it works

  1. npx retirement-radar scanyour own AWS credentials
  2. Every regionread-only describe calls
  3. Six servicesEKS, RDS, ElastiCache, OpenSearch, MSK, Lambda
  4. retirements.yamlevery date with its AWS source
  5. The reportretired, extended, soon, upcoming, and the cost

Decisions that matter

  • Read-only by design, enforced by tests: it can only describe, never change.
  • Every date links to the AWS page it came from, and the whole table was re-checked against AWS on 5 October 2026.
  • Services are table-driven, so adding one is a row and a collector, not a rewrite.

Shipping it

  1. Tag

    A version tag runs the full checks.

  2. Stage

    npm publish is staged from CI with provenance through a trusted publisher. No long-lived token exists.

  3. Approve

    A human approves the staged release with a second factor before anyone can install it.
