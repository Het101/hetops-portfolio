    Work · every tool starts as a problem

    01From a bad week to Threadvault

    A chat migration broke 7,200 threads. The repair became an open-source CLI.

    1. 01

      The move

      A resource move replayed 7,200 Azure Communication Services chat threads onto a new resource, with participants turned off.

    2. 02

      The damage

      7,022 messages showed the wrong author, and every thread rejected replies with CommunicationError Forbidden.

    3. 03

      The repair

      Both defects were fixable only because the extract had kept each message's original sender and every participant list.

    4. 04

      The tool

      I wrote the post-mortem, then turned the repair into Threadvault: an open-source CLI that finds these failures before a migration does.

      Source Post-mortem
    7,200 threads replayed
    Old resourceNew resource
    participants: off
    7,022 messages with the wrong author CommunicationError Forbidden every thread, on reply
    -author: system
    +author: metadata.originalSenderUserId
    +participants: restored from extract
    history preserved, authors restored

    02Live at dns.hetops.dev

    DNS Intelligence

    The problem An SPF record that needs more than 10 DNS lookups fails, and nested includes hide the real count.

    A domain scanner with 26 checks across DNS, TLS, security headers, DNSSEC, email authentication and reputation. It counts SPF lookups through every nested include, the way mail servers do.

    Free for one domain. Pro and Team plans, from $5 a month, add monitoring, alerts on certificate, SPF, DMARC, MX and nameserver changes, and automatic DMARC report collection.

    How I ship

    The same bar for side projects as for production. Every repo enforces it, not just describes it.

    Every pull request

    Nothing reaches main until all of this is green, and nothing reaches npm until I approve it with 2FA.

    1. test (20 · 22 · 24)unit tests and a real run of the built artifact
    2. hygieneworkflow audit, secret scan, signed and conventional commits
    3. analyzeCodeQL security and quality queries
    4. stagenpm publish staged from CI, with provenance

    Gfeat(spf): count DNS lookups through nested includes Gfix(security): block IPv4-mapped IPv6 in every written form Gfeat: scan ElastiCache, OpenSearch and MSK Gfix(auth): never build sign-in links from request headers Gbuild: Node 22 two-stage image, and CI that runs it Gfeat(spf): count DNS lookups through nested includes Gfix(security): block IPv4-mapped IPv6 in every written form Gfeat: scan ElastiCache, OpenSearch and MSK
