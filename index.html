      Threadvault

      A chat migration broke 7,200 threads. The repair became an open-source CLI.

      1. The move

        A resource move replayed 7,200 Azure Communication Services chat threads onto a new resource, with participants turned off.

      2. The damage

        7,022 messages showed the wrong author, and every thread rejected replies with CommunicationError Forbidden.

      3. The repair

        Both defects were fixable only because the extract had kept each message's original sender and every participant list.

      4. The tool

        I wrote the post-mortem, then turned the repair into Threadvault: an open-source CLI that finds these failures before a migration does.

      DNS Intelligence

      An SPF record that needs more than 10 DNS lookups fails, and nested includes hide the real count.

      A domain scanner with 26 checks across DNS, TLS, security headers, DNSSEC, email authentication and reputation. It counts SPF lookups through every nested include, the way mail servers do.

      Free for one domain. Pro and Team plans, from $5 a month, add monitoring, alerts on certificate, SPF, DMARC, MX and nameserver changes, and automatic DMARC report collection.

      Retirement Radar

      AWS bills automatically for running old versions. EKS extended support alone is about $365 a month per cluster.

      A read-only CLI that scans every region for EKS, RDS, ElastiCache, OpenSearch, MSK and Lambda versions at or near end of support, with the AWS source for every date. npm installs last month.

      npx retirement-radar scan

      Or let it run for you: Radar Cloud connects through a read-only role and scans every account on a schedule (weekly free, daily on paid), with email and Slack alerts and the monthly cost of each finding.

      Restore Drill

      A backup job that says "success" proves nothing. You only learn the file is empty, stale or corrupt on the day you need it.

      Every six hours it pulls the newest offsite backup of each database, restores it into a throwaway copy (SQLite, or a PostgreSQL server it starts for the test), checks integrity, row counts and freshness, then destroys the copy. It alerts by Slack, Discord or email when a drill starts failing.

      It drills the DNS Intelligence, Radar Cloud and Analytics databases today, and its evidence page is public.
