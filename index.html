Open-source CLI on npm

Threadvault

A chat migration replayed 7,200 threads with participants turned off. 7,022 messages showed the wrong author and every thread rejected replies. I repaired it, wrote the post-mortem, then turned the repair into a tool.

  • doctor finds the five failure modes before a migration does
  • mirror copies chat into your own Postgres under your own user ids
  • verify proves the destination matches the source

Turns HDFC bank statements into Tally ERP 9 vouchers for five family books. Every run must tie to the bank's own totals, and it refuses to guess: if a row could belong to two ledgers, the whole run stops.
