      Threadvault

      A chat migration broke 7,200 threads. The repair became an open-source CLI.

      1. The move

        A resource move replayed 7,200 Azure Communication Services chat threads onto a new resource, with participants turned off.

      2. The damage

        7,022 messages showed the wrong author, and every thread rejected replies with CommunicationError Forbidden.

      3. The repair

        Both defects were fixable only because the extract had kept each message's original sender and every participant list.

      4. The tool

        I wrote the post-mortem, then turned the repair into Threadvault: an open-source CLI that finds these failures before a migration does.

      DNS Intelligence

      An SPF record that needs more than 10 DNS lookups fails, and nested includes hide the real count.

      A domain scanner with 26 checks across DNS, TLS, security headers, DNSSEC, email authentication and reputation. It counts SPF lookups through every nested include, the way mail servers do.

      Free for one domain. Pro and Team plans, from $5 a month, add monitoring, alerts on certificate, SPF, DMARC, MX and nameserver changes, and automatic DMARC report collection.

      Retirement Radar

      AWS bills automatically for running old versions. EKS extended support alone is about $365 a month per cluster.

      A read-only CLI that scans every region for EKS, RDS, ElastiCache, OpenSearch, MSK and Lambda versions at or near end of support, with the AWS source for every date. npm installs last month.

      npx retirement-radar scan

      Or let it run for you: Radar Cloud connects through a read-only role and scans every account on a schedule (weekly free, daily on paid), with email and Slack alerts and the monthly cost of each finding.

      Restore Drill

      A backup job that says "success" proves nothing. You only learn the file is empty, stale or corrupt on the day you need it.

      Every six hours it pulls the newest offsite backup of each database, restores it into a throwaway copy (SQLite, or a PostgreSQL server it starts for the test), checks integrity, row counts and freshness, then destroys the copy. It alerts by Slack, Discord or email when a drill starts failing.

      It drills the DNS Intelligence, Radar Cloud and Analytics databases today, and its evidence page is public.

      How I ship

      The same bar for side projects as for production. Nothing reaches main until the ring closes, and nothing reaches npm until I approve it with 2FA.

      main
      1. testNode 20, 22 and 24, plus a real run of the built artifact
      2. hygieneworkflow audit, secret scan, signed and conventional commits
      3. analyzeCodeQL security and quality queries
      4. stagenpm publish staged from CI, with provenance
      5. approvea human, with a second factor

      Signed, protected main

      Signed commits, linear history, required checks and no force-push on every repository.

      • feat(spf): count DNS lookups through nested includes
      • fix(security): block IPv4-mapped IPv6 in every written form
      • fix(auth): never build sign-in links from request headers

      Careful dependencies

      Dependabot waits 7 days before proposing a release, every Action is pinned to a commit, and new dependencies are reviewed for advisories and licences.

      Least privilege

      Read-only by design where possible, enforced by tests. Credentials hashed at rest. Releases need no stored token.

      Break it The GitOps repo
      • GitOps

        Argo CD makes git the only way in. Delete a deployment by hand and it is recreated from git within a minute.

      • SLO

        99% of visits must succeed over any 7 days. When the error budget is spent, experiments freeze until it recovers.

      • mTLS

        Linkerd encrypts every hop from the ingress to the database. Postgres accepts four named identities only: a pod that passed the network rules was still refused.

      • Logs

        Every request, from ingress to database, lands in Elasticsearch on one timeline.

      • Audit

        The Kubernetes audit log records who did what. A shell opened in a pod raises an alert mapped to MITRE ATT&CK.

      • Runtime

        Falco watches system calls on the node and reports what actually ran inside a container, down to the command.

      • Edge

        CrowdSec spots scanners in the access logs, and their IP is blocked at Cloudflare’s edge within two minutes.

      • Images

        Every running image is scanned weekly. The first scan found 75 high and critical CVEs; today it finds none.

      • Changes

        All of it lands in one feed: every deploy, scale, sync, experiment and alert. When an alert fires, the Change Timeline lists the changes just before it; a killed pod shows up 0.2 seconds after the click.
